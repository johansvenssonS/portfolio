# Portfolio Legacy

This directory contains a copy of the vanilla JavaScript portfolio from the `johansvenssonS/portfolio` repository.

## Structure
- `index.html` - Main HTML file
- `style.css` - All styling
- `src/main.js` - Entry point for custom elements
- `src/project.js` - Projects component
- `src/projects.json` - Projects data
- `src/view/landing.js` - Landing view component
- `img/` - Images directory (needs manual copy)

## Images Required
The following images need to be manually copied from the original portfolio repo:
- `backgrund.jpg` (background image)
- `Tåg-Monter.png`
- `spellcheckeer.png`
- `yahtzee.png`
- `Tipsvänner.png`

## Running Locally
1. Use a local server (e.g., `python -m http.server` or VS Code Live Server)
2. Open `index.html` in your browser
